Build first: Run npm run build from the project root, then serve with python3 -m http.server 8080 and open http://localhost:8080/demo_dropin_ui.html.

How this page works: The entire instrument — piano keyboard, duration buttons, rest button, mode toggle, triplet button, notation area, and playback controls — is created by a single mountFullUI('#full-ui', options) call. Click ⚙ Advanced to access key/time signature, barline mode, and display toggles.

Type ABC directly: If you know ABC notation you can type structural tokens and ornaments straight in — they don't collide with the note keys. Type | for a barline, |: … :| for repeats, |1 … :|2 for volta endings, or a decoration like !trill!, a chord symbol "Gm", or grace notes {gc}. A live indicator by the ⚙ Advanced button shows the token and whether it parses (✓ / ✗ invalid) — an invalid token is never committed. Backspace edits the in-progress token; Esc cancels it.

Touch: On a phone or tablet, tap the on-screen piano keys to enter or play notes. Hold two fingers down simultaneously to enter a chord (simultaneous notes). All buttons are touch-friendly.
