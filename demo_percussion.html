qwerty-abc-piano — percussion mode

Rhythm-only input on a one-line percussion staff, mounted with percussionMode: true, shellToggle: false so the page starts in percussion mode and has no Piano/Percussion toggle.

What this shows: percussionMode: true records every note at one fixed pitch, so only rhythm matters. With shellToggle: false the Piano/Percussion toggle bar is hidden and the UI stays locked to percussion. The notation is drawn on a one-line staff via the %%stafflines 1 directive.

The "Last ABC passed to abcjs" panel above shows the full ABC string (header included) rendered on each keystroke, so you can see exactly what the library produces.

Playing: Click TAP or press any letter/number key to enter a note. Every note is recorded as B4, written B (the middle line of the percussion staff). Duration keys 1–6 still work. Press Z to insert a rest.
